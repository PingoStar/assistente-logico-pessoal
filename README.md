# Assistente Lógico Pessoal

Sistema desenvolvido para a disciplina de Linguagem de Programação e Paradigmas (LPP - Sistemas de Informação - UNIDAVI), integrando uma base de conhecimento em **SWI-Prolog** com uma interface de terminal em **Python**.

## Como executar
1. Certifique-se de ter o **SWI-Prolog** (`swipl`) e o **Python 3** (`python`) instalados e configurados no PATH do sistema.
2. No terminal, dentro da pasta `assistente-logico-pessoal`, execute:
   ```bash
   python assistente.py
